Important prototype information

About this build

This is an early, locally functioning prototype to test the layout and user experience.

What works in this version

  • Responsive navigation and page layouts
  • Library category browsing and search
  • Pin and unpin demo references using browser storage
  • Metric / imperial conversion
  • Circle circumference calculation
  • Rotational speed calculation
  • Searchable starter thread chart

What is not connected yet

  • No user accounts or login
  • No cloud database or cross-device syncing
  • No payment processing or live subscriptions
  • Library entries are starter placeholders, not complete technical articles
  • Thread data is illustrative starter data and must be verified before workshop use
Safety and accuracy: this prototype is for demonstration and general information only. It is not a substitute for approved engineering documentation, workplace procedures, competent assessment or applicable standards.
