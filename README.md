# Fitters Black Book — Prototype 1.0

A free, static website prototype designed to be published with GitHub Pages.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new repository named `fitters-black-book`.
2. Choose **Public** for the simplest free GitHub Pages setup.
3. Upload `index.html` to the repository root (the top level, not inside another folder).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish. The site address will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/fitters-black-book/`

## Prototype scope
- Responsive dashboard and navigation
- Ten Library categories with search
- Pin categories to My Bench (saved in this browser's local storage)
- Searchable starter metric coarse thread table
- Metric/inch conversion, circle circumference and RPM calculators
- Membership pricing preview

## Important limitations
This is a front-end prototype only. It has no real accounts, private member data, cloud database, payment processing or cross-device sync. Pins are stored only in the browser/device where they are created. Thread data is starter reference material and must be checked against current standards and engineering documentation before workshop use. The calculations are general-purpose aids and are not engineering approval.
